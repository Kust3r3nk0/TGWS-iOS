# TGWS-iOS · оформление и визуальные материалы

## Концепция

Стиль: **Premium Minimal**. Основные цвета: тёмный графит `#080E1B`, насыщенный синий `#111E37`, холодный синий `#55A9FF`, мятный `#75E3D4`. Для репозитория используются статичные SVG без удалённых ресурсов и JavaScript.

## Иллюстрации репозитория

- `docs/images/tgws-ios-cover.svg` — редакционный баннер TGWS-iOS с абстрактным изображением iPhone и маршрутов данных.
- `docs/images/tgws-ios-stack.svg` — диаграмма используемых и запланированных технологий.

**Эти рисунки — визуализация проекта, не проверенные скриншоты работающего iOS-приложения.** Баннер сознательно не содержит заявления о готовности сетевого движка.

## Оригинальный логотип

Изображения README не изменяют и не заменяют исходный логотип TGWS-Android. В итоговой iPhone-сборке нужно сохранить **согласованный оригинальный знак и имя приложения**, предварительно проверить исходные файлы и права на использование изображения. Заглушку `AppIcon` в стартере не принимать за финальную иконку.

Запрещено представлять чужой товарный знак, включая Apple, Telegram или OpenAI, как официальный знак TGWS без необходимых прав. Изображения устройств и интерфейсов должны быть собственными или иметь подходящую лицензию.

## Правила для новых материалов

1. Не публиковать реальные URL приватных Worker, MTProto-секреты, личные идентификаторы и скриншоты с чувствительными данными.
2. Любой макет интерфейса подписывать «Концепт» до сборки и проверки на iPhone.
3. Скриншоты GitHub Releases получать из работающей сборки; указывать версию и платформу.
4. Отмечать статус `F0 / F1 …` исходя из результатов тестирования, не подменять испытания схемой.
5. Исходные изображения и сторонние шрифты добавлять только после проверки прав; векторные иллюстрации текущего README используют системные шрифты.
