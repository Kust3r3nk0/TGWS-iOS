# Security Policy — TGWS-iOS

Проект находится в исследовательском статусе. Стабильная версия отсутствует.

## Сообщения об уязвимостях

Не публикуйте действующие секреты, private Worker URL, персональные данные, подробности пригодных для эксплуатации уязвимостей или токены в публичных Issue/PR. Используйте **GitHub private vulnerability reporting**, если владелец репозитория включил его. Если приватный канал не настроен, сначала попросите сопровождающего предоставить защищённый способ связи **без раскрытия подробностей уязвимости**.

## Требования безопасности

- Секреты и URL реле — Keychain, без логирования.
- Только loopback listener; никаких публичных портов.
- Строгие TLS trust и hostname checks.
- Ограничения сессий, таймаутов, памяти, ретраев и отмены операций.
- Relay-only никогда не переходит на direct.
- Не воспроизводить payload после неопределённой доставки.
- Не использовать фальшивые механизмы фоновой работы или частные iOS API.

Статус поддержки безопасности и срок реагирования пока не заявлены.
