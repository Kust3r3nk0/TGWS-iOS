# Участие в разработке TGWS-iOS

Проект находится на стадии исследования. Перед PR изучите `AGENTS.md`, `CODEX_TASK.md`, `docs/TECHNICAL_SPEC_RU.md` и `docs/IOS_FEASIBILITY.md`.

## Процесс

1. Откройте Issue, указав воспроизводимый сценарий и ожидаемое поведение без приватных данных.
2. Внесите изменения в отдельную ветку `feature/*` или `fix/*`. Не включайте изменения в Android/Worker инфраструктуре.
3. Добавьте автоматические тесты, фиксированные эталонные векторы и отрицательные сценарии для сетевых изменений.
4. Для каждой новой фичи обновите `docs/PORTING_MATRIX.md` и пользовательский статус README.
5. В PR укажите реальную среду, команды, результаты тестов, ограничения и инструкцию проверки владельцем на iPhone.

**Тесты на симуляторе не заменяют тестов на физическом iPhone.** Не добавляйте эмуляцию успеха или небезопасные механизмы фонового исполнения.

## Локальная проверка

```bash
cd Packages/TGWSCore && swift test && cd ../..
xcodegen generate --spec project.yml
xcodebuild -project TGWSiOS.xcodeproj -scheme TGWSiOS -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Наличие этих команд не означает, что они уже прошли. В отчёте указывайте фактические результаты.

## Лицензирование

Сохраняйте атрибуцию MIT для исходников и протокольных фикстур. Не копируйте несвободные шрифты, изображения или закрытые элементы Apple/Telegram в репозиторий.
